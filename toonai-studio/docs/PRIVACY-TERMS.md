# Privacy and Terms placeholders

Before Play Store production, replace this file with legally reviewed Privacy Policy and Terms covering:
- account data
- uploaded images/video
- generated content
- AI providers
- storage retention
- analytics/ads
- payments
- deletion/export requests
- prohibited content
- copyright and impersonation/voice-cloning restrictions
- grievance/contact details

The app includes an account deletion API and project deletion API; production must also define retention/deletion of S3 objects, provider-side assets, logs, backups, and payment records where legally required.
